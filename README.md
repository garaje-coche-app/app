# Mi Garaje — app para tu Ford

App para ver el estado de tu coche Ford (con FordPass Connect) desde el móvil: viajes, consumo, repostajes, mantenimiento, neumáticos y más.

- **App del móvil:** https://garaje-coche-app.github.io/app/
- **Tu servidor (gratis en Cloudflare):** carpeta [`plantilla`](plantilla) → botón *Deploy to Cloudflare*.

Cada persona tiene su propio servidor y sus propios datos; nadie ve los de nadie.
